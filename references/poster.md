# 海报：先明确目的，再设计

仅用于【海报】、【图文海报】或 poster 路由。海报用视觉和文字促成一次明确的认知、情绪或行动；好看不等于达成目的。可以简洁，也可以丰富，不预设巨幅标题、满版夜景、复杂建筑或戏曲人物。

## 必须明确的信息

以下四项是设计简报的最低要求。用户可用一句自然语言一起说明，也可沿用明确的上下文，不要求逐项填表。

| 必需项 | 要明确什么 | 示例 |
|---|---|---|
| 宣传对象与主题 | 为谁或什么做海报，核心内容是什么 | 常州中秋文旅，而非泛中秋祝福 |
| 首要目的与预期结果 | 看完希望受众记住、感受到或采取什么行动；多目标先定主次 | 让人想来常州过中秋；或促成恐龙园购票，两者不同 |
| 目标受众 | 主要对谁说，影响内容选择与语气 | 周边城市年轻游客、亲子家庭、已有客户 |
| 投放场景 | 发布渠道、观看方式，已有尺寸限制 | 手机社媒传播、景区入口印刷、商场远距离灯箱 |

风格编号需确定或委托代选，按主技能处理。交付形式、数量沿用主技能；不能因选海报就默认授权生图。

缺少会改变设计方向的必需项时，一次简短询问缺项，可给出建议选项，但不要擅自把“来常州”解释成亲子购票或编造受众。可以先整理已知约束和备选方向，不把未明确的目的当作定稿。用户明确委托代定时，用合理假设推进，并在方案开头列明假设。已经明确的信息不重问。

### 按目的触发的必需资料

| 海报目的或约束 | 定稿前必须有的资料 |
|---|---|
| 活动报名或到场 | 准确活动名、日期时间、地点，以及实际报名／到场方式；截止时间、费用等影响参与的条件如适用也要提供 |
| 购买、优惠或产品转化 | 商品／服务、真实卖点、购买入口；若宣传价格、折扣、有效期和限制，必须提供准确内容 |
| 品牌或官方发布 | 准确名称；要求使用标志、产品图、品牌色或署名时，提供对应素材或规范 |
| 扫码、访问网址或联系咨询 | 真实目标地址、二维码文件或联系方式；不让图像模型凭空画一个可用二维码 |
| 必留景点、人物、文字或事实 | 明确清单，区分必须画出与必须印字；涉及现实活动、营业信息等事实须有可靠依据 |
| 严格复刻建筑、产品或人物外观 | 可用参考图；普通艺术化地标表达不强制索要写实参考 |
| 最终印刷交付 | 成品尺寸，以及承印方要求的出血、分辨率和色彩规格；没有规格时只能交设计预览，不声称印刷就绪 |

仅做城市形象、节日氛围或品牌认知时，不强制增加价格、日期、二维码或行动按钮。条件资料缺失时只补问影响当前目的的部分；可先做概念方案并标待补资料，不能编造信息或把带占位符的稿件称为可发布成品。

### 可默认或代拟

- 标题、辅助文案、视觉概念、配色、密度、构图由设计决定，不要求用户先写完。
- 手机社媒且无指定规格时可暂用竖版 3:4，一张；在方案中注明。印刷和特定版位不套此默认。
- 参考海报、口吻、禁用元素可选；提供后应遵守。参考作品只作指定的 STYLE 或 LAYOUT 参考，不复制其文案、城市地标、标志或活动事实。
- 是否需要行动文案由目的决定；认知或情绪目标可以不设置显式行动入口。

可供用户直接填写的简报：

```text
交付模式：提示词／图片／图片及提示词
类型：海报
画风：编号或委托代选
宣传对象与主题：
首要目的（看完希望观众记住／感受／做什么）：
目标受众：
投放场景（有固定尺寸请注明）：
必留内容或文字：无则写无
与目的相关的事实及素材：活动／价格／入口／品牌资料等，仅按需提供
```

这是收集简报的模板，不是最终生图提示词，不能把未填写字段带入交付文件。

## 设计流程与方案展示

1. **目的句。** 用一句话明确“向谁，在什么场景，传播什么，使其产生什么结果”。列出必要事实与假设，确定唯一首要目标。
2. **传播重点。** 选择最值得记住的核心信息，以及支撑它的具体理由。每个主要元素应承担识别、吸引、说服、说明或行动中的一种作用；删掉只添热闹却削弱重点的内容。
3. **视觉策略。** 按目的选择文字、人物、场景、产品或地标作为主导，不强制列多套。决定主焦点、视觉动线、疏密、色彩对比，以及必要的前中远景。极简海报不强塞空间层次；丰富海报不平均摆放全部元素。
4. **文字层级。** 先创作主标题，再按需要加入辅助说明、场景文字和行动信息。主题不自动成为标题。逐项列出实际要印的文字、位置、层级与锁定范围；事实准确，字号适应投放环境，不靠缩成小字容纳所有内容。
5. **风格应用。** 保留选定画风的墨线、造型、材质和色彩语言；独立决定海报构图。若画风默认低密度而方案需要丰富城市环境，明确“保留人物与线条语言，环境密度按海报设计调整”，不要同时要求大量留白和全幅密集场景。角色不是每张海报的必需品。
6. **展示可确认方案。** 顺序为“目的与受众 → 投放规格 → 核心信息 → 视觉概念与层级 → 完整上图文字 → 必留资料及待补项”。用一句话说明视觉和文案如何服务目的，不能仅展示景物清单。遵守主技能的两阶段交付规则。

城市文旅海报应根据受众选择游玩理由，让景点形成有主次的城市体验；别把所有景点等大拼贴，也别让通用角色压过城市辨识度。艺术化地标组合可以使用，但不伪装成实景地理关系。此为适用案例，不是所有海报的固定模板。

## 完整提示词要求

确认后按 [rendering.md](rendering.md) 保存 `poster-prompts.md`，如重名选新文件名。每张海报一个独立可复制的提示词，必须展开以下已确定内容，不留占位符：

- 海报类型、每次一张、数量与具体比例／尺寸、投放场景。
- 传播目的、受众与核心信息，明确这些是创作方向，不是全部待印文字。
- 画风编号、生成名称及所需视觉特征；密度与空间等调整写成一致的最终指令。
- 具体主视觉、元素主次、位置关系、视觉动线、配色及适合观看距离的对比。
- 全部上图文字及其位置、层级；明确必须准确的文字与事实，按需加入实际行动入口。
- 必留元素、真实资料及有效边界，不杜撰优惠、地理关系或活动承诺。
- 参考素材按交付模式处理：提示词模式面向 ChatGPT 网页时，画风参考仅在每个可复制提示词中写一次“以该图作为艺术风格参考。”，不写本地路径、文件名、STYLE 标签、输入序号、附件角色表或上传说明；直接生图时才记录实际附件及 STYLE／LAYOUT／PERSON／品牌素材用途。

不套用“一段文案”“禁止信息区域”或分镜模板。若实际二维码、标志、小字等须后续排版，应保留明确空间并标注待排版；未完成前不得称为可直接发布或印刷成品。

## 以目的验收

- 第一眼能否识别宣传对象与核心信息？焦点是否明确，而非只有节庆装饰？
- 内容与语气是否适合目标受众？具体视觉与文案是否支持预期认知、情绪或行动？
- 需要报名、购买、到场时，关键条件和真实入口是否完整、可读、可用？不需要转化入口时是否避免硬塞按钮？
- 在实际渠道的观看尺寸／距离下，主次、对比、安全边距和必要文字是否成立？
- 必留事实、品牌、参考用途是否正确？是否用错字、伪二维码或夸张承诺损害目的？

提示词交付只能验收方案完整性与目的匹配；图片生成后按主技能的有限重试和视觉检查规则验收。不得把设计判断说成已经证明传播效果或转化率。
