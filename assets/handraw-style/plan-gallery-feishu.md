# 手绘风格画廊 · 飞书知识库整理计划

## 目标
把 handraw-style 仓库中「无法直接浏览」的本地 HTML 画廊（`skills/handdraw-style-prompter/gallery/`），整理为一份**飞书知识库**，设置**公开链接**（拿到链接即可阅读、无需登录），让不用 Codex 或无法打开本地页面的人也能浏览全部画廊内容。

## 已确认需求
- 形态：飞书知识库（Wiki），多文档组织
- 范围：全部四块 —— 风格画廊（278 种）+ 图型画廊（120 种）+ 色彩画廊（30 种）+ 使用教程
- 权限：公开链接（互联网上获得链接的人可阅读）
- 语言：中文为主（风格英文名保留原名）

## 素材盘点（已探查，全部齐备，无需用户补充）
| 内容 | 数据源 | 配图 |
| :-- | :-- | :-- |
| 278 种风格 | `references/styles.json`（编号/分组/作者/风格名/特征） | `images/` 下 18 张拼图（A_001-016…H_265-278）+ `images/individual/` 278 张单图 |
| 120 种图型 | `references/layouts.json`（分类/名称/关键词）+ `references/layouts/*.md`（提示词） | `images/layouts/` 社媒卡20 / 信息图32 / 漫画分镜68 |
| 30 种色彩 | `references/colors.json`（中英名/色系/引用语/中英提示词） | `images/colors/C-01…C-30.webp` |
| 教程 | `TUTORIALS.md` + `README.md` | `images/poster-demo-autumn-equinox.webp`、群二维码等 |

├── 03 · 色彩画廊       30 张色卡 + 色系分类 + 中文名/引用语/中文提示词

## 执行步骤
1. **读取素材**：完整解析 styles.json / layouts.json / colors.json、120 个 layout 提示词 md、TUTORIALS.md、README.md 关键章节，核对编号-名称-作者-特征映射。
2. **读 Skill 确认能力**：读取 `lark-wiki`、`lark-doc` 的 SKILL.md，确认建空间、建文档、批量插图、表格、公开权限设置的具体方式；若公开链接权限受租户设置限制，记录并采用可行替代（组织内可见+单独分享），执行时向用户说明。
3. **上传图片**：将所需的本地图片（约 170+ 张：18 拼图 + 120 图型 + 30 色卡 + 教程配图 + 群二维码）通过 FileBatchUpload 上传获取 URL，供文档嵌入；分批执行避免限流。
4. **创建知识库**：用 lark-wiki 创建知识空间，设置公开链接权限；创建上述 5 篇文档。
5. **写入内容**：按结构逐篇写入正文、插入图片、生成速查表；程序化生成 278 行风格速查表以保证编号-名称-作者-特征对应准确。
6. **验证**：逐篇打开返回的文档链接，检查文字/图片/表格渲染、编号连续性、权限是否生效；核对 278/120/30 数量。
7. **交付**：通过 present_files 交付知识库首页链接与各分册链接，附使用说明。

## 决策点（执行中处理，不阻塞）
- **风格配图策略**：主文档嵌入 18 张拼图（快览选号）+ 速查表（文字定位）。278 张单图默认不逐张嵌入（体量过大、收益有限）；如需单图可在文档中另设目录页按需补充。
- **文档拆分**：若单篇「风格画廊」过长，按拼图分组 A–H 拆为小节或分篇，保持浏览顺滑。

## 风险与备选
- 飞书「互联网公开」权限可能受租户/管理员设置限制 → 改用「组织内获得链接可阅读」并向用户说明差异。
- 大批量插图可能触发接口限流 → 分批上传、失败重试。
- 公开后内容与仓库同步维护：本次为一次性整理快照，后续仓库更新需重新生成（可复用本流程）。

## 无需用户额外提供
现有素材与数据已覆盖全部四块内容。仅需确认本计划即可开工。
